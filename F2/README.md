# FITRIDE Animated Frontend

FITRIDE is an animation-first shared mobility frontend. It preserves the 234-frame scroll-controlled vehicle story, the custom animated FITRIDE logo, the bottom-left cinematic copy, and the interactive booking/fleet demo screens.

## Run locally

```bash
cd "/Users/saikiran3103/Downloads/Sedan-door-opens-interior-view-2 2"
npm start
```

Open `http://127.0.0.1:3100`.

The booking, fleet, and admin interactions run in local demo mode and are stored in the browser so the frontend works without a backend service.
